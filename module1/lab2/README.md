# Lab 2


## Description

In this lab, we continued familiarizing ourselves with the Pi by setting up a local backup service through ssh and scp. We accomplished this by setting up an ssh key on the local computer and allowing the pi to use that key for scp without password. We put this into another [script](/raspberrypi/scripts/local_autobackup.sh) and experimented with using crontab to have it run every 10 minutes (and then disabled it after confirming that it worked).
