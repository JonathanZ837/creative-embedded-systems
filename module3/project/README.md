# Dynamic Breathing Exercises
Author: Jonathan Zeng
## Description

![Animation of breathing exercise](breathingexercise.gif)
Dynamic Breathing Exercises is an installation art about creating a personal breathing exercise for the viewer based on the way they approach the exhibit. The two distance sensors will analyze the viewers speed, gait, and other factors about how they walk to determine a unique and personalized animation on the monitor for them to breathe to.

## How to use

Set up the detection sensor (the green box) sideways around 3 meters away from the monitor. Open the green box and flip on the LiPo rider on switch to "on". Connect the detection sensor (blue box) to the monitor with the HDMI cable and plug in the USB-C cable with the power supply. Shortly after the raspberry pi powers on, the animation should appear on the screen, due to the setup script being run as an autostart service. You may now interact with it as shown.
