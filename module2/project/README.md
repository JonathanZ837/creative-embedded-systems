# Quantum Clock
Author: Jonathan Zeng
## Description

The quantum clock is a creative interactive device about time. Unlike an ordinary clock, it only shows the true time when “observed”, otherwise the state of the clock is unknown. In this case, being “observed” simply means when a bright enough light is shone onto the top of the clock.

## How to use

Using a USB cable, plug in the device from the left port on the side into a power source. The display may flash some while it connects to the internet. After a few seconds, the quantum clock should start running. To observe the clock, flash a bright light, such as a phone flashlight, onto the hole on the lid.
